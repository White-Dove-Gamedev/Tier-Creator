### Creating Issues

Issues may be of any kind, whether they're about bug reports, or feature requests.

For bug reports, mention the steps that need to be taken in order to recreate it.

For feature requests, justify why it should be implemented and how it can be done. Keep those features as simple as possible. If necessary, create sub-issues to break it down even further.

### Creating Pull Requests

Pull requests may only be made if it closes an existing issue and should therefore be mentioned with a closing remark at the beginning of a Pull request. Additionally, add a summary on what has been implemented.

### Guidelines

When creating pull requests, make sure to follow the Godot [GDScript Style guide](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html). However as there is currently no linter in place, it is not very important to follow every rule. But please do not neglect it.

The most important rule to follow is to statically type function returns.
